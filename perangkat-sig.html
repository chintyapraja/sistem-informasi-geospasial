Tujuan Pembelajaran

Setelah mempelajari materi ini, mahasiswa mampu mengidentifikasi perangkat yang digunakan dalam SIG dan menjelaskan fungsi setiap perangkat dalam suatu pekerjaan survei dan pemetaan.

1. Hardware

Mengenali perangkat untuk akuisisi, pemrosesan, penyimpanan, dan penyajian data.

2. Sistem Operasi

Memahami peran OS sebagai lingkungan untuk menjalankan perangkat lunak SIG.

3. Software

Memilih perangkat lunak berdasarkan fungsi dan kebutuhan pekerjaan.

1. SIG adalah sebuah sistem

SIG tidak hanya berarti aplikasi pemetaan. Pekerjaan SIG berjalan melalui hubungan antara perangkat keras, sistem operasi, perangkat lunak, data, dan pengguna.

Hardware→ Sistem Operasi→ Software SIG→ Data→ Informasi
Pertanyaan utama: perangkat apa yang digunakan, untuk fungsi apa, dan pada tahap mana perangkat tersebut dibutuhkan?

Spesifikasi komputer: mengapa penting?

RAM

Mempengaruhi kemampuan membuka data besar dan menjalankan beberapa proses sekaligus.

CPU

Mempengaruhi kecepatan berbagai proses komputasi dan geoprocessing.

GPU

Penting untuk visualisasi 3D, beberapa proses citra, dan aplikasi yang memanfaatkan akselerasi grafis.

Storage

SSD mempercepat akses file. Kapasitas menjadi penting untuk citra satelit, UAV, dan data point cloud.

Open-source dan commercial/proprietary software

JenisPengertianContoh dalam SIGCatatan
Open-source Kode sumber tersedia dan pengguna dapat mempelajari, menggunakan, serta memodifikasi perangkat lunak sesuai ketentuan lisensinya. QGIS, GeoServer, PostgreSQL/PostGIS, GDAL Open-source tidak selalu berarti tanpa biaya pada seluruh layanan pendukung. Lisensi tetap harus diperhatikan.
Commercial / proprietary Perangkat lunak dikembangkan dan didistribusikan oleh pemilik tertentu dengan ketentuan lisensi penggunaan. ArcGIS Pro, ENVI Umumnya memerlukan lisensi atau hak akses tertentu. Fitur dan biaya bergantung pada produk serta paket lisensinya.

GUI-based dan programming-based geospatial tools

Perangkat lunak geospasial juga dapat dibedakan berdasarkan cara pengguna berinteraksi dengannya.

PendekatanCara kerjaContohKegunaan
GUI-based Pengguna bekerja melalui menu, toolbar, panel, dialog, dan mouse. QGIS, ArcGIS Pro Cocok untuk visualisasi, editing, layout, analisis interaktif, dan pembelajaran awal SIG.
Programming / scripting-based Pengguna menulis kode atau script untuk memanggil fungsi geospasial. Python dengan GeoPandas/Rasterio, R, JavaScript pada Google Earth Engine Cocok untuk otomatisasi, analisis berulang, pemrosesan banyak data, dan workflow yang reproducible.
Hybrid Menggabungkan antarmuka grafis dengan scripting atau model pemrosesan. QGIS + PyQGIS, ArcGIS Pro + ArcPy Pengguna dapat bekerja secara interaktif, lalu mengotomatisasi proses yang sama dengan script.
Poin penting: GUI dan programming bukan dua dunia yang terpisah. Banyak software SIG modern mendukung keduanya. Mahasiswa dapat memulai dari GUI untuk memahami konsep, kemudian menggunakan scripting untuk otomatisasi dan analisis yang lebih kompleks.

AI-assisted Development

12. Vibe Coding dalam Pekerjaan Geospasial

Vibe coding adalah cara membuat atau mengubah program dengan bantuan AI melalui instruksi bahasa alami. Pengguna menjelaskan apa yang ingin dibuat, kemudian AI membantu menulis atau memperbaiki kode.

Penting: vibe coding bukan pengganti pemahaman dasar pemrograman. Kode hasil AI tetap harus diperiksa, diuji, dan divalidasi oleh pengguna.

Contoh dalam bidang geospasial

KebutuhanContoh penggunaan vibe coding
Automasi GISMeminta AI membuat script Python untuk batch clipping beberapa shapefile.
Remote sensingMembuat script Google Earth Engine untuk menghitung NDVI atau mengekstrak time series.
Data processingMembuat script untuk mengubah format, membaca metadata, atau menggabungkan banyak file.
Web GISMembuat tampilan peta interaktif menggunakan JavaScript dan library pemetaan web.
Quality controlMembantu membuat script untuk mengecek nilai NULL, duplikasi, atau geometri bermasalah.

Contoh sederhana

Instruksi ke AI:

“Buat script Python menggunakan GeoPandas untuk membaca semua shapefile dalam satu folder, mengubah CRS menjadi EPSG:32750, lalu menyimpan hasilnya ke folder baru.”

Hasil: AI dapat membantu menghasilkan draft script. Pengguna kemudian memeriksa CRS, nama file, folder, error handling, dan hasil spasialnya.

Kelebihan dan risiko

KelebihanRisiko
Mempercepat pembuatan script awal.Kode dapat salah walaupun terlihat meyakinkan.
Membantu pengguna yang baru belajar coding.Pengguna dapat memakai fungsi yang tidak dipahami.
Membantu debugging dan dokumentasi.Kesalahan CRS, unit, parameter, atau logika spasial dapat menghasilkan hasil yang salah.
Mempermudah eksplorasi workflow baru.Data sensitif tidak boleh diberikan sembarangan ke layanan AI.
Prinsip aman: gunakan AI untuk membantu menulis kode, bukan untuk menggantikan proses verifikasi. Dalam SIG, selalu periksa input, CRS, unit, parameter analisis, dan hasil pada peta.

15. Contoh Kasus dan Pembahasan

Soal: Sebuah tim akan memetakan perubahan penggunaan lahan menggunakan UAV dan melakukan pengecekan lapangan menggunakan GNSS. Hasil akhir harus berupa peta digital yang dapat dibagikan melalui internet.

Pertanyaan: Perangkat apa saja yang dibutuhkan dan apa fungsi masing-masing?

Jawaban dan pembahasan

Tahap Perangkat yang digunakan Fungsi Mengapa dibutuhkan?
Akuisisi citra UAV + kamera Merekam foto udara area penelitian. Foto udara menjadi data utama untuk melihat kondisi dan perubahan penggunaan lahan secara detail.
Posisi lapangan GNSS/GPS Merekam koordinat titik lapangan, titik kontrol, atau lokasi pengecekan. Koordinat dibutuhkan agar data lapangan dapat dihubungkan dengan lokasi yang benar pada peta.
Pemrosesan data Laptop/workstation dengan CPU, RAM, GPU, dan SSD yang memadai Menjalankan pengolahan citra UAV, analisis spasial, dan visualisasi. Data UAV umumnya berukuran besar sehingga memerlukan komputer dengan kemampuan pemrosesan dan penyimpanan yang cukup.
Sistem operasi Windows atau Linux Menjalankan perangkat lunak pengolahan dan SIG. Sistem operasi menjadi lingkungan tempat aplikasi bekerja serta mengatur hardware komputer.
Pengolahan fotogrametri Software fotogrametri Mengolah foto UAV menjadi orthomosaic, DSM, atau point cloud. Foto UAV mentah perlu diproses terlebih dahulu sebelum dapat digunakan sebagai data pemetaan.
Analisis SIG QGIS atau ArcGIS Pro Membuka layer, mengedit data, melakukan query, klasifikasi, analisis spasial, dan membuat peta. Software SIG digunakan untuk menggabungkan data UAV, GNSS, dan data pendukung lain menjadi informasi geospasial.
Penyimpanan SSD/HDD, server, atau basis data spasial Menyimpan citra, layer, atribut, hasil analisis, dan proyek. Data geospasial harus disimpan secara terstruktur agar mudah digunakan kembali dan dibagikan.
Distribusi GeoServer atau platform Web GIS Mempublikasikan layer dan peta agar dapat diakses melalui jaringan atau internet. Hasil akhir tidak hanya disimpan di komputer, tetapi dapat dibagikan kepada pengguna lain.
Kesimpulan kasus: satu pekerjaan SIG tidak diselesaikan oleh satu perangkat saja. UAV dan GNSS digunakan untuk memperoleh data, komputer dan sistem operasi menjalankan proses, software SIG digunakan untuk mengelola dan menganalisis data, sedangkan server atau Web GIS digunakan untuk membagikan hasil.

Pertanyaan diskusi singkat

1. Apakah QGIS atau ArcGIS Pro dapat menggantikan UAV?

Jawaban: Tidak. UAV adalah perangkat akuisisi data, sedangkan QGIS dan ArcGIS Pro adalah perangkat lunak untuk mengelola, menganalisis, dan menyajikan data. Fungsinya berbeda.

2. Apakah komputer dengan spesifikasi tinggi selalu diperlukan dalam SIG?

Jawaban: Tidak selalu. Kebutuhan komputer bergantung pada ukuran data dan jenis proses. Data vektor sederhana dapat diproses dengan komputer biasa, sedangkan citra UAV, point cloud, atau analisis raster besar memerlukan sumber daya yang lebih tinggi.

3. Mengapa software SIG berbeda-beda?

Jawaban: Karena setiap software dirancang untuk fungsi tertentu. QGIS dan ArcGIS Pro kuat untuk pekerjaan desktop GIS, GeoServer untuk publikasi layanan geospasial, dan Google Earth Engine untuk pengolahan data geospasial skala besar berbasis cloud.

4. Mana yang lebih penting, hardware atau software?

Jawaban: Keduanya saling bergantung. Software tidak dapat berjalan tanpa hardware, dan hardware tidak dapat melakukan pekerjaan SIG tanpa software yang sesuai.
